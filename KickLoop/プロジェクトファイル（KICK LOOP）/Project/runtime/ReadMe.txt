KICK LOOP

Windows 10／11のx64環境（DirectX 11対応）で、実行フォルダー一式を展開して KICKLOOP.exe を起動します。
Visual StudioやSDKのインストールは不要です。
タイトル画面ではマウスで「START」に視点を合わせて左クリックします。

このソフトウェアには、（株）ＣＲＩ・ミドルウェアの「CRIWARE」が使用されています。
