### 収録内容

- 実行動画

### 起動・選択手順

DynamicBreaker.exeを起動し、以下の順に選択してください。

**PvE → SOLO → 緑のペンギン → ICE**

ICEステージで、担当したシャチのギミックをご確認いただけます。

### 対応状況

- モード：PvE（SOLO / MULTI）
- キャラクター：緑のペンギン
- ステージ：ICE / SCRAP

PvP、JUNGLE、赤・紫・灰色のペンギンは未対応です。
MULTIを選択後にSOLOで遊ぶ場合は、ゲームを再起動してください。
